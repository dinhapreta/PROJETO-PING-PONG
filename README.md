# 🏓 Jogo Ping-Pong em HTML5

Este projeto é um jogo simples de Ping-Pong desenvolvido com **HTML5, CSS3 e JavaScript puro**. Foi criado como exercício prático durante um curso online, e publicado aqui para fins de portfólio profissional.

## 🎮 Funcionalidades

- Jogo de Ping-Pong com movimentação da bola e colisão com as raquetes
- Pontuação automática (jogador e computador)
- A IA do computador segue a bola
- Controle do jogador com o movimento do mouse
- Estilo simples com fundo colorido e linha divisória central
- Código organizado diretamente em um único arquivo (`index.html`)
- Versão complementar: `linha_divisoria.html` para teste da linha central

## 🛠️ Tecnologias usadas

- HTML5 (`<canvas>`)
- CSS3 (reset e cor de fundo)
- JavaScript puro (sem bibliotecas externas)

## 📁 Estrutura dos Arquivos

📦 projeto-ping-pong
├── index.html → jogo completo
├── estilo.css → estilos básicos (fundo e container)
├── linha_divisoria.html → exemplo de linha e raquete fixa


## 📲 Como jogar

1. Acesse o jogo:
   👉 https://dinhapreta.github.io/PROJETO-PING-PONG/

2. Mova o mouse para controlar a raquete esquerda
3. A raquete direita é automática
4. Acompanhe a pontuação no topo da tela

## ✨ Objetivo

Este projeto foi criado como forma de aprendizado e prática, e também para demonstrar conhecimento em lógica, DOM e uso de `<canvas>`.
